# LearnQuest - Gamified Learning App

## Project Overview

LearnQuest is a mobile UI/UX design project created in Figma.

The application uses gamification techniques to improve learning through:

- XP Points
- Daily Challenges
- Badges
- Leaderboards
- Progress Tracking
- Rewards

## Screens

- Splash Screen
- Home Dashboard
- Continue Lesson
- Daily Challenge
- Achievements
- Profile
- Leaderboard
- Design System

## Tools Used

- Figma
- SVG
- UI Design
